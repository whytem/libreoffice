# Computational Substrate Formula-Group Listener-Anchor Live Support Contract

Status: frozen contract for the FormulaGroup listener-anchor live-support closeout

## Live-Owned Listener Kinds

This cycle widens live-owned listener-anchor handling only to:

- `FormulaCell`
- `FormulaGroup`

This cycle still keeps the following outside contract:

- `HostUnknown`

## First Live-Owned Surface

The first live-owned surface for true `FormulaGroup` listener anchors is:

- already-admitted same-sheet shareable shared-group live apply
- already-admitted shared-group final verification
- already-admitted shared-group mutation-entry carry-through

The cycle also reruns one previously blocked follow-on candidate:

- bounded named-range-combined same-text preserve

That rerun is for blocker removal proof only. It is not an automatic
admission.

## Explicit Non-Goals

This contract does not claim ownership of:

- arbitrary host-only listener kinds
- `HostUnknown` listeners
- off-sheet shared-group surfaces
- repair-sensitive host normalization
- broader named-range-combined regroup, merge, or member-exit classes
- synthetic destructive restore surfaces as newly admitted workbook classes

## Exactness Standard

True listener-anchor support only counts as owned when the live path still
meets the existing exactness bar:

- no listener-kind mismatch is waived
- no broadcaster mismatch is treated as acceptable
- queue, computational, graph, and final-verification comparisons remain
  authoritative

If a surface no longer rejects out of contract but still misses exact state,
that surface remains explicitly non-admitted.
