## Current Navigation Model

The computational-substrate effort accumulated many individual
`COMPUTATIONAL_SUB*.md` plan, contract, schema, evidence, implementation,
and decision documents across multiple passes.

Those documents are still retained in this directory, but they are now
historical detail rather than the recommended way to understand the program.

Use them only when you need:

- implementation archaeology for a specific closed pass
- original decision context for a narrow boundary choice
- detailed evidence behind a settled conclusion

For day-to-day understanding, use the master document instead.
